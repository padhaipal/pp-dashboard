3.) Data: on every change of (current entity id, metric, range) fetch `GET geo-entities/:id/scores?metric=&range=` and `GET geo-entities/:id/spotlight?metric=&range=` in parallel (spotlight failure is tolerated → null). Results are keyed by `id|metric|range` so stale responses never render. Defaults: metric `nipun_g3`, range 30. `:id` is a geo entity id or, in the class view, the teacher's user id (pp-sketch resolves both on the same endpoint).

UNNAMED`) follows one save.
