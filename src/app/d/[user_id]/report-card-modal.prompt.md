1.) "use client" report blocks (used on the page AND inside the modal), all from API data:
  a.) `RepKpis({ root, metricLabel, nounP, usingN, totalN, asOf, range, showUsing })` — cards: "{pass_rate}% · n={n}" (bin colour), students_active, `MvpTrend(delta)` "last {range} days", "{usingN} of {totalN} {nounP} using Lifteracy"; footer "as of {as_of}".
  b.) `RepTrend({ series, label })` — `data-rep-chart="trend"`, root pass-rate line over `series` dates, 80 % target, mobile-aware viewBox (`useIsMobile`, 640 px), INLINE styles/attributes only so it rasterises for the PDF. "No results in this window" when every point is null.
  c.) `RepLatest({ childrenRows, ... })` — `data-rep-chart="latest"`, one bar per child sorted by pass rate (`sortedLatest`), bin colours, grey `#e5e7eb` full-height bar for children not using Lifteracy, hover/select/double-click hooks.
  d.) `RepImproved({ mostImproved, ... })` — horizontal bars by `delta` (green positive, red negative), "Not enough data yet (needs n ≥ 5)." when empty.
  e.) `RepQuote({ kind, entry, nounS, officer })` — spotlight card: "Top {noun} — {pass}%" or "Most improved — +x pts", official avatar/name/role_title, `spotlight_message` in quotes ("No spotlight message yet." / "No Lifteracy user yet" fallbacks; dashed placeholder when entry is null).
  f.) `RepMeta({ child, metricLabel, officer })` — detail card tinted by the child's bin colour: name, official, "Latest {metric} · n · students active", MvpTrend.
2.) `ReportCardModal({ data: ReportData, onClose })` — preview (Lifteracy header, KPIs, trend, latest, most improved, both quotes, share link) with a "Download PDF" button. `exportReportPdf` loads jsPDF ONLY via a dynamic `import("jspdf")` inside that handler (never a static import — enforced by jspdf-lazy.test.ts) and draws ONE A4 page with jsPDF primitives: title "{location} Report", subtitle (metric · range · as of), KPI boxes, the trend rasterised from the on-screen `svg[data-rep-chart="trend"]` via canvas `toDataURL` → `addImage`, latest bars and most-improved bars as rects, spotlight quotes, footer with generation time (IST), share link, metric, window. File name `lifteracy-{location}-report.pdf`.
