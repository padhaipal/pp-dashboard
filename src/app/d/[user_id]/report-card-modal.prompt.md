1.) "use client" report blocks (used on the page AND inside the modal), all from API data, markup/classes from mvp2.html; each takes an optional `t` (i18n) that defaults to identity:
  a.) `RepKpis({ root, metricLabel, nounP, usingN, totalN, showUsing, t })` — mvp2's cards: "{pass_rate as whole %}" (`nipColor`) labelled "average {metric}", and when `showUsing` "{usingN} of {totalN} {nounP} using Lifteracy" coloured by `nipColor(usingN / totalN × 100)` (0 of 13 → red; mvp2 hardcoded green). Nothing else (no n, no students active, no change, no as-of).
  b.) `RepTrend({ series, label?, metric?, students?, hoverId?, setHoverId?, pinId?, setPinId?, t })` — `data-rep-chart="trend"`, mvp2's spaghetti chart. The root line (navy, labelled "Average" at its last point) plots `SeriesPoint.mean` for every metric — mean score × 100 for the tests, mean minutes for usage — i.e. the average of the student lines, never the pass rate. For usage the x-axis labels are shifted one day back (`shiftDay`) because a row dated D holds the previous IST day, so the series ends at yesterday. The y-axis follows the metric: 0–100 with the red dashed "80% NIPUN target" for nipun_g2/g3, 0–100 without a target for mpl_b, and minutes for usage (ticks every 10 up to max(30, next multiple of 10 above the data), no target). `students` (class view; `TrendStudent = {id, label, points: {date, value}[]}` from `ScoresResponse.students_series`) adds one faint grey line each (1.4 px, opacity 0.9; null points are gaps; `data-testid="student-line"` / `data-student-id`); the hot line (`pinId ?? hoverId`) is blue 2.4 px on top with the student's label at its end (`data-hot="1"`), the others dim to 0.3 and the average to 0.55. Hovering a line sets `hoverId`, clicking toggles `pinId`. y-axis caption = `label` at 11 px (12 mobile) 600 weight, else the NIPUN sentence. Mobile-aware viewBox (`useIsMobile`, 640 px), INLINE styles/attributes only so it rasterises for the PDF. "No results in this window" when every point is null.
  c.) `RepLatest({ childrenRows, ... })` — `data-rep-chart="latest"`, one bar per child sorted by pass rate (`sortedLatest`), bin colours, grey `#e5e7eb` full-height bar for children not using Lifteracy. Used ONLY by the report modal / PDF — mvp2's page has no latest-bars chart.
  d.) `RepImproved<R extends ImprovedRow>({ mostImproved, ... })` — generic over `{ id, name, delta }` rows (geo children, teachers, or the class view's students); horizontal bars by `delta` (green positive, red negative), rows 19 px; renders NOTHING when there is no ranked row (mvp2 returns null — the heading stays).
  e.) `RepQuote({ kind, entry, nounS, officer, range, t })` — spotlight card: "Top {noun} — {whole %}" or "Most improved — +x pts last {range} days", official avatar (h-14, 2 px ring)/name/role_title, `spotlight_message` in quotes ("No spotlight message yet." / "No Lifteracy user yet" fallbacks; dashed "No {noun} qualifies yet." placeholder when entry is null).
  f.) `RepMeta({ child?, student?, metricLabel, officer, range, t })` — mvp2's detail card: left half tinted by `nipColor` (`px-5 py-5`; avatar h-20, name, official name, role), right half ONE headline figure "{whole %}" + `MvpTrend(delta, "last {range} days")` over the label "Latest {metric}". `student` shows label / "Student" / "{attempts} attempts", no avatar, and the arrow from `StudentChild.delta` when the student has a score.
2.) `ReportCardModal({ data: ReportData, onClose })` — preview (Lifteracy header, KPIs, trend, latest, most improved, both quotes, share link) with a "Download PDF" button; `ReportData.childType` may be "student" (school level). `exportReportPdf` loads jsPDF ONLY via a dynamic `import("jspdf")` inside that handler (never a static import — enforced by jspdf-lazy.test.ts) and draws ONE A4 page with jsPDF primitives: title "{location} Report", subtitle (metric · range · as of), the mvp2 KPI boxes (average metric; using count above school level), the trend rasterised from the on-screen `svg[data-rep-chart="trend"]` via canvas `toDataURL` → `addImage`, latest bars and most-improved bars as rects, spotlight quotes, footer with generation time (IST), share link, metric, window. File name `lifteracy-{location}-report.pdf`.
