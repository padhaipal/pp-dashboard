1.) EN / हिं dictionary for the public dashboard, ported from mvp2.html's `I18N` table (report strings only) plus the handful of strings that exist only here (student cards, up button, save). No React, no DOM.
2.) `Lang = "en" | "hi"`, `LANGS` (toggle labels "EN" / "हिं"), `LANG_STORAGE_KEY = "lifteracy-dashboard-lang"`, `isLang`.
3.) `translate(lang, s)` / `makeT(lang)` → `t(s)`: the Hindi string when `lang === "hi"` and one exists, else `s` unchanged — an untranslated string is never an error. Metric labels ("NIPUN grade 3 proxy") are NOT translated, exactly as in mvp2.
4.) Strings are looked up by their English text (mvp2 convention), so composed headings translate piecewise: `t("Student") + " " + t("Detail")`.
