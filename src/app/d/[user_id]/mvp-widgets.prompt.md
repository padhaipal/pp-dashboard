1.) "use client" widgets ported from mvp2.html, all fed by API data:
  a.) `AvatarImg({ seed, size, ring })` — `next/image` (unoptimized) of `/api/avatar/sprouts-v10/{seed}` (`seedFor` falls back to "lifteracy").
  b.) `MvpTrend({ delta, suffix })` — zig-zag arrow: green up, red down, grey flat when |Δ| < 0.5 or null; text "+1.5 pts" (null → "—").
  c.) `MvpMetricToggle` — three buttons "NIPUN grade 2 proxy" / "NIPUN grade 3 proxy" / "MPL-B proxy" (`aria-pressed`).
  d.) `MvpRangeBar({ range, setRange, entityId, metric })` — "30 days" / "90 days" + "Download CSV" anchor (`data-testid="csv-link"`, target _blank) whose href is `csvUrl(entityId, metric, range)` = `/api/proxy/geo-entities/{id}/scores.csv?metric={metric}&range={range}` — always the CURRENT metric and range.
  e.) `MvpShareBar({ shareLink, explainerUrl })` — "Share your dashboard link" caption, the link in large mono text (scheme stripped for display, `data-testid="share-link"`), "Copy" button (clipboard; label "Copied!" for 1.6 s), and "What is Lifteracy?" link to `explainerUrl` — `profile.explainer_url` from `/users/:id/public`, omitted entirely when null (no dead anchor, no placeholder).
  f.) `MvpStudentTrend({ series, label })` — pass-rate line (0–100, 80 % red dashed target, gaps on null points, last value labelled), inline styles only.
  g.) `MvpStudentActivity({ series })` — last 7 series points: green rounded bar sized by `n` when n > 0, pink stub otherwise.
2.) `MvpTeacherModal({ subject, metric, onClose })` — opens from ANY child row. `subject.kind === "child"`: header with `child.official` (avatar, name or "No Lifteracy user yet", role_title or the level's officer), stat tiles (pass rate · n, students active, MvpTrend, using Lifteracy), its own metric + range toggles, fetches `GET geo-entities/{child.id}/scores` for `MvpStudentTrend` + `MvpStudentActivity`, and the official's spotlight message as a quote. `kind === "student"`: label · "Student", tiles for score (0–1 → %), passed, attempts, in_band, active, last_active_at (IST). Esc or backdrop closes.
3.) Server errors: Nest `{ message }` (string | string[]) else `HTTP <status>`.
