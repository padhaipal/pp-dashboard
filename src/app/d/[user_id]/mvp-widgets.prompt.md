1.) "use client" widgets ported from mvp2.html, all fed by API data:
  a.) `AvatarImg({ seed, size, className, ring, ringWidth = 3, shadow })` — `next/image` (unoptimized) of `/api/avatar/sprouts-v10/{seed}` (`seedFor` falls back to "lifteracy"); `ring` draws a `0 0 0 {ringWidth}px` box-shadow, `shadow` is appended after it (mvp2's profile-photo drop shadow).
  b.) `MvpTrend({ delta, suffix })` — mvp2's zig-zag arrow: green up, red down, grey flat when |Δ| < 0.5 or null; text "+1.8%" + suffix (e.g. "last 30 days"); null → "—".
  c.) `MvpMetricToggle` — three buttons "NIPUN grade 2 proxy" / "NIPUN grade 3 proxy" / "MPL-B proxy" (`aria-pressed`), mvp2 classes (`text-xs`, `px-3 py-1.5`, active `bg-blue-600`).
  d.) `MvpRangeBar({ range, setRange, entityId, metric, t })` — "30 days" / "90 days" (active `bg-zinc-900`) + "Download CSV" anchor (`data-testid="csv-link"`, target _blank, `hidden sm:block` like mvp2) whose href is `csvUrl(entityId, metric, range)` = `/api/proxy/geo-entities/{id}/scores.csv?metric={metric}&range={range}` — always the CURRENT metric and range. Rendered inside the Performance card's "Trend" row, as in mvp2.
  e.) `MvpLangToggle({ lang, setLang })` — mvp2's EN / हिं switch (`aria-pressed`, active button filled with the accent).
  f.) `MvpStudentTrend({ series, label })` — pass-rate line (0–100, 80 % red dashed target, gaps on null points, last value labelled), inline styles only.
  g.) `MvpStudentActivity({ series })` — last 7 series points: green rounded bar sized by `n` when n > 0, pink stub otherwise.
  There is no share bar widget any more — mvp2 defines `MvpShareBar` but never renders it, and the page follows mvp2.
2.) `MvpTeacherModal({ subject, metric, onClose, t })` — mvp2's modal (`max-w-6xl bg-zinc-50`, white header row `px-6 py-4`, "✕ Close"). Opens from the Detail card (geo child / teacher) or a student tile. `subject.kind === "child"`: header avatar + "{name} · {role}", `MvpStudentActivity` from that entity's series, its own metric + range toggles (with CSV), `MvpStudentTrend` from `GET geo-entities/{child.id}/scores`, and the official's spotlight message as a quote. `kind === "student"` (mvp2's student dashboard): header "{label} · Student" + `MvpStudentActivity` over the last 7 IST days of voice notes (`activitySeries`), metric + range toggles (no CSV), `MvpStudentTrend` over the student's score history (`GET users/:id/literacy-test-scores` → `historySeries`: the toggled test's `history[]` within the range, score × 100), then a `max-h-80` scroll pane with one sentence per voice note from `GET users/:id/media` (newest first): "At {7:29pm} on {Thursday} {this week | last week | N weeks ago} the student said [▶ audio | nothing (no recording)] and the correct answer was {answer, ≤14 chars} and so was marked as {correct | incorrect | not assessed}." — `whenParts` (IST). `AudioButton` creates one `<audio>` on first click from `/api/proxy/media-meta-data/{id}/audio` and toggles play/pause (▶ / ❚❚). Both student fetches are tolerated individually (null → that part is empty; both failing shows "Could not load this student"). Esc or backdrop closes.
