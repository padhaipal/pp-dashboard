1.) "use client" `GeoMap` — d3 + SVG choropleth (no MapLibre). Boundaries are fetched on demand per drill level from `/boundaries/{type}/{code}.geojson` and cached in module scope (`loadBoundary`, de-duplicated in-flight). The district and block views sit on mvp2's CARTO Positron `light_nolabels` raster underlay (`tileUrl`, the one external host): `tiles` inverts the viewport corners through the Mercator projection, picks the zoom where one tile is ≈≤520 px, pads 40 % for panning, caps at 120 tiles and places each `<image>` by projecting its NW/SE corners (`data-testid="tile-underlay"`, "© OpenStreetMap contributors © CARTO" bottom-right). No tiles at country/state level. Keyless CARTO raster tiles are watermarked "API KEY REQUIRED" (since Aug 2026): `NEXT_PUBLIC_CARTO_KEY` (free key, carto.com/basemaps/apikey; build-time) is appended as `?key=` when set. The "© OpenStreetMap contributors © CARTO" attribution must stay — it is the condition of the free tier.
2.) Per level (`childType` = type of the children, never "teacher"/"student"): state → every child state polygon (country outline underneath); district → state outline + child district polygons — the polygon file is tried for EVERY child regardless of `has_boundary` (that flag is stamped at seed time from the boundaries manifest and goes stale; hierarchy rows have no lat/lng to fall back on, so trusting it left whole states empty), children whose file is missing render as labels at lat/lng when they have one; block → tiles + district border (`fill="none"` over tiles) + one label per block at its `lat/lng` (blocks have no polygon; null coords → no label); school → tiles + one marker per school at `lat/lng` and NO border — a dot for government / aided / other schools, a 45°-rotated `<rect>` (diamond, `data-management="private"`) for `management_group === "private"`, both on the same score colour, with a small "Government school / Private school" legend block (`data-testid="school-kind-legend"`) and "· private school" in the tooltip; only OPERATIONAL schools arrive (pp-sketch `descendants()` filters status + deleted_at) (mvp2: schools straight on the street underlay; `parentDistrict` is no longer read), schools with null coords sit at the block's point + `jitterLatLng` (≤ 300 m, `data-jittered`, tooltip "· approximate location"). School and class levels have no map (teacher cards / student tiles replace it).
3.) Fill: `childFill` (score colour; `UNCOVERED` grey when `using_lifteracy` false or no score). Legend `bottom-3 left-3` (mvp2): "Latest {metric}" ≥80 `#16a34a` / 50–79 `#f59e0b` / <50 `#dc2626` / Not using Lifteracy grey (+ "Boundaries pending" black swatch at the state level when any state is incomplete). Strings go through the optional `t` prop.
4.) INCOMPLETE STATES (`incompleteStates` Set of 2-digit codes from districts_without_boundary.csv): fill `#000000`, `data-incomplete="true"`, cursor not-allowed, click AND double-click are no-ops, hover tooltip "District boundaries not yet available for this state"; they carry no score colour (excluded from the choropleth scale).
5.) Interactions: hover → `setHoverId` + tooltip (name, "pass% · n=N" or "Not using Lifteracy"); single click → `onSelect(child)`; double-click → `onDrill(child)`. Mouse drag pans (pointerType mouse only so touch scrolls the page); a drill resets pan/zoom. +/− buttons top-right (`data-testid="map-zoom"`, `zoomBy` around the viewport centre, k clamped 0.5–40) at every map level; no "double-click to drill" pill; the up-a-level button is the PAGE's, bottom-right of the map card. `data-code`, `data-id` attributes on interaction paths for tests.
6.) Projection: `fitMercator` over outline + child polygons, else `pointsFeature` of the points. Size from a ResizeObserver on the wrapper (defaults 640×420 where unavailable); the wrapper is `h-full` — the page's map card fixes the height (460 px, mvp2).
7.) `areaFill(d, child, incomplete)` helper kept from mvp2.
