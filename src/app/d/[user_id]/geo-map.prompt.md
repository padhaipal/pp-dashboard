1.) "use client" `GeoMap` — d3 + SVG choropleth only (no MapLibre, no tiles, no external hosts). Boundaries are fetched on demand per drill level from `/boundaries/{type}/{code}.geojson` and cached in module scope (`loadBoundary`, de-duplicated in-flight).
2.) Per level (`childType` = type of the children): state → every child state polygon (country outline underneath); district → state outline + child district polygons, children with `has_boundary` false render as labels at lat/lng; block → district outline + one label per block at its `lat/lng` (blocks have no polygon; null coords → no label); school → parent district outline + one dot per school at `lat/lng`, schools with null coords sit at the block's point + `jitterLatLng` (≤ 300 m, `data-jittered`, tooltip "· approximate location"). School level itself has no map.
3.) Fill: `childFill` (score colour; `UNCOVERED` grey when `using_lifteracy` false or no score). Areas with no Lifteracy user also get a greyscale `PlusButton` "+" at the centroid. Legend `bottom-3 left-3` (mvp2): "Latest {metric}" ≥80 `#16a34a` / 50–79 `#f59e0b` / <50 `#dc2626` / Not using Lifteracy grey (+ "Boundaries pending" black swatch at the state level when any state is incomplete). Strings go through the optional `t` prop.
4.) INCOMPLETE STATES (`incompleteStates` Set of 2-digit codes from districts_without_boundary.csv): fill `#000000`, `data-incomplete="true"`, cursor not-allowed, click AND double-click are no-ops, hover tooltip "District boundaries not yet available for this state"; they carry no score colour (excluded from the choropleth scale).
5.) Interactions: hover → `setHoverId` + tooltip (name, "pass% · n=N" or "Not using Lifteracy"); single click → `onSelect(child)`; double-click → `onDrill(child)`. Mouse drag pans (pointerType mouse only so touch scrolls the page); a drill resets pan/zoom. No zoom buttons and no "double-click to drill" pill — mvp2 replaced zoom with the up-a-level button, which the PAGE renders bottom-right of the map card. `data-code`, `data-id` attributes on interaction paths for tests.
6.) Projection: `fitMercator` over outline + child polygons, else `pointsFeature` of the points. Size from a ResizeObserver on the wrapper (defaults 640×420 where unavailable); the wrapper is `h-full` — the page's map card fixes the height (460 px, mvp2).
7.) `areaFill(d, child, incomplete)` helper kept from mvp2.
